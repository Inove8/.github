# Inove8 · `.github`

This repository holds the public face and shared defaults for the [Inove8](https://www.inove8.com) GitHub organisation.

| Path | What it does |
| --- | --- |
| `profile/README.md` | The landing page shown at [github.com/Inove8](https://github.com/Inove8) |
| `profile/assets/` | Banner and call-to-action graphics used by the profile |
| `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, `SECURITY.md`, `SUPPORT.md` | Default community files for every Inove8 repo that doesn't define its own |
| `.github/ISSUE_TEMPLATE/`, `.github/pull_request_template.md` | Default issue forms and PR template for all repos |

To update the profile, edit `profile/README.md` and commit to `main` — changes show up on the organisation page immediately.
